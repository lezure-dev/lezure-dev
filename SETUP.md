# efkay GitHub profile README

The profile SVGs are generated by `generate_profile.py` and refreshed by `.github/workflows/update-profile.yml`.

## Dynamic data

- Uptime is recalculated in `America/Chicago`.
- Repos = repositories owned by the profile account.
- Contrib = distinct repositories the account has contributed to through commits, issues, pull requests, or PR reviews.
- Stars = total stars across repositories owned by the profile account.
- Followers = current GitHub follower count.
- Lines of Code on GitHub = current `cloc` code-line total across owned, non-fork repositories. Generated/vendor/build folders are excluded. LOC is cached for 7 days; the cheaper GitHub counts refresh daily.

Without an extra token, the generator can still read public profile/repository data. Private repositories require an Actions secret.

## Include private repositories

Create a read-only GitHub token that can access the repositories you want counted, then add it to the profile repository as an Actions secret named:

`PROFILE_GITHUB_TOKEN`

For private repositories owned by the same personal account, a fine-grained token with access to the desired repositories and **Contents: read** is sufficient for the LOC clone step; repository metadata is used for counts/stars. If private contributed repositories span organizations or other owners, the token/GitHub App must also have read access to those repositories under the relevant organization policies.

The token is only supplied to the generator at workflow runtime. `stats_cache.json` stores aggregate numbers only; it does not store repository names or the token.

## Theme

Dark mode:
- background `#000000`
- ASCII + values `#FFFFFF`
- labels `#00FF41`
- structural dots/lines `#7AA2F7`

Light mode:
- background `#FFFFFF`
- ASCII + values + structural dots/lines `#000000`
- labels `#D0006F`

The README automatically selects `assets/dark_mode.svg` or `assets/light_mode.svg` from the viewer's GitHub color scheme.
